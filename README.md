## 🚀 About Me
I code because I can't sit still. Because I don't trust black boxes. Because when I see a problem, I need to understand it and solve it myself.

By day, I'm a Data Management Specialist. Meetings, strategy, stakeholder plans. It's a layered cake, decorated, the kind you serve at important occasions. People are impressed. 

But at night, I'm in my terminal building things no one asked for. That's pancakes. Simple batter, hot pan, your own two hands. 
No one's taking photos. No one's impressed. But that first bite, when it's still warm and you made it yourself? Nothing else comes close.
